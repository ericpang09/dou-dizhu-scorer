# 鬥地主計分器 (Dou Dizhu Scorer)

一個靚爆嘅鬥地主計分網頁應用。設定玩家、記錄每局、睇勝率統計，Supabase 雲端同步。

## 快速開始

直接 double-click `index.html` 就開到，或者放上任何 static host。

## 功能

- 👥 玩家管理（自訂名）
- ➕ 新增一局：選地主/農民、設底分、勾倍數、春天/反春天、即時計分預覽
- 📊 紀錄一覽（編輯/刪除/展開詳情）
- 📈 統計：個人總輸贏、地主勝率、農民配對勝率
- ☁️ Supabase 雲端同步（多裝置）+ localStorage 離線後備

## 雲端同步

後台已設定好，用戶完全唔使理。雲端自動同步，離線時存本機。

### 開發者：首次建立資料表（一次性）

anon key 唔可以建立 tables。首次部署時，去 Supabase Dashboard → SQL Editor，貼入 `supabase/schema.sql` 撳 Run。之後用戶就咁開 app 就自動同步。

## 計分規則

- 每人分 = 底分 × 總倍數（炸彈×2, 王炸×4, 明牌×4, 叫地主×2, 自訂）× 春天倍數（春天×2 / 反春天×2）
- 地主贏：地主 +（每人分 × 2），兩農民各 −每人分
- 農民贏：兩農民各 +每人分，地主 −（每人分 × 2）
