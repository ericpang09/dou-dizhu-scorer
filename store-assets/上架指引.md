## 步驟 1：建立應用程式

1. 入 https://play.google.com/console
2. 撳右上角 **「建立應用程式」**（Create app）
3. 填：

| 欄位 | 填咩 |
|------|------|
| 應用程式名稱 | `鬥地主計分器` |
| 預設語言 | `中文（繁體）— 香港` |
| 應用程式或遊戲？ | **應用程式**（App） |
| 免費或付費？ | **免費** |
| 宣告 | ✅ 全部 3 格都剔（美國出口、內容政策、使用者資料） |

4. 撳 **「建立應用程式」**

## 步驟 2：填寫主要商店資訊

去左邊欄 **「拓展」→「主要商店資訊」**（Main store listing），填：

### 應用程式詳細資料

**應用程式名稱**：`鬥地主計分器`

**簡短說明**（80 字內）：
```
鬥地主記分神器！多人即時同步、勝率統計、地主農民配對分析
```

**完整說明**（複製下面全部）：
```
🃏 鬥地主計分器 — 同朋友打牌最方便嘅記分工具

✨ 主要功能
• 一鍵記局：點一下邊個做地主，另外兩個自動做農民，即時計分
• 完整計分規則：底分 × 倍數（炸彈、火箭、搶地主、春天、反春天）
• 即時同步：多人入同一個房間碼，任何一個記局，其他人即時見到
• 房間隔離：唔同班朋友用唔同房間碼，互不干擾
• 實時積分榜：頂部顯示每人贏緊/輸緊幾多
• 勝率統計：個人總輸贏、地主勝率、農民配對勝率
• 紀錄管理：所有局數自動保存，可修改可刪除
• 雲端備份：唔怕換手機或清快取，記錄永遠喺度
• 離線可用：冇網都記到分，有網自動同步

🎯 點用
1. 第一個人開新房間，得到房間碼
2. 朋友輸入同一個房間碼入房
3. 打牌時點一下邊個做地主，選倍數，揀邊邊贏
4. 分數自動計算同同步俾所有人
5. 隨時睇勝率統計同歷史紀錄

💡 適合
• 同朋友/家人打鬥地主時記分
• 公司/學校比賽記錄
• 想知道自己同邊個拍檔最夾

完全免費，冇廣告，冇註冊。即裝即用。
```

## 步驟 7：上傳 AAB（最關鍵）

去左邊欄 **「發布」→「正式版」**（Production）→ 撳 **「建立新版本」**

1. **Play 應用程式簽署**：Google 會問你要唔要佢幫你管理 signing key
   - 揀 **「使用 Google 產生的金鑰」**（推薦，Google 會幫你保管，最安全）
   - 或者 **「使用現有金鑰」** upload 我哋嘅 keystore
   
   👉 **建議揀「Google 管理」**，咁你唔使驚 keystore 唔見

2. **App Bundle**：upload `app-release.aab`

3. **版本名稱**：`1.0.0`

4. **版本資訊**：
```
首次推出 🎉

• 一鍵記局 + 即時計分
• 多人即時同步（房間制）
• 完整計分規則（炸彈、火箭、春天等）
• 實時積分榜
• 勝率統計（地主勝率、農民配對勝率）
• 雲端備份
```

5. 撳 **「下一步」→「檢查版本」→「開始正式版發布」**

## ❓ 常見問題

**Q：點解審核要咁耐？**
A：首次上架一定慢，之後更新會快好多（通常 1-2 日）。

**Q：會唔會唔通過？**
A：鬥地主計分器冇敏感內容（冇真錢賭博、冇暴力、冇廣告），通常都會過。如果唔過，Google 會 email 話你知點解，forward 俾我幫你改。

**Q：要唔要免責聲明？**
A：Play Store 描述可以加一句「本 App 只供計分用途，唔涉及真錢賭博」。如果要，我幫你加。
